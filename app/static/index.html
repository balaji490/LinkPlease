How to Use LinkPlease

Follow these steps to automate your Instagram DMs

QUICK START
1

Create a Keyword Rule

Type a trigger keyword such as PRICE or LINK, then write the DM message to auto-send.

Keywords match anywhere in the comment text, case-insensitive.
2

Simulate a Comment

Use the Webhook Simulator to fire test events. Click "New Comment Match" to trigger the rule.

Try "Same User Again" to see the idempotency guard in action.
3

Watch the DM Queue

The Activity Feed updates live. Jobs move from Pending to In Flight to Delivered.

The reconciler polls for delayed failures and retries automatically.
4

Monitor Live Stats

The stat cards show real-time counts from SQLite refreshing every 3 seconds.

Visit /docs for the full REST API reference with Swagger UI.
